# MathPHP specifications

Normative and project-level specifications for MathPHP. These documents define
the language contract, identity decisions, and implementation traceability.

- [`V0.1-CONTRACT.md`](V0.1-CONTRACT.md) — grammar, numeric behavior, errors, limits, and API contract
- [`V0.1-TRACEABILITY.md`](V0.1-TRACEABILITY.md) — requirement-to-test audit
- [`IDENTITY-GATE.md`](IDENTITY-GATE.md) — package and namespace identity decision

Implementation: https://github.com/mathphp/mathphp
Documentation: https://github.com/mathphp/mathphp-docs
